# Temporia

A small sleep-cycle calculator that helps choose bedtime or wake-up times around 90-minute cycles.

**[Open the demo](https://temporia.vercel.app)**

## What it does

- Calculates wake-up times from the current time
- Calculates bedtimes from a target wake-up time
- Includes a power-nap option and sleep-cycle recommendations
- Accounts for an estimated 14 minutes to fall asleep
- Works as an installable progressive web app

This is a planning aid, not medical advice. Sleep needs vary from person to person.

## Development

```bash
bun install
bun run dev
```

Build and preview the app with:

```bash
bun run build
bun run preview
```
